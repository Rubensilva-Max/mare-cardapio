# Maré — Peixe interativo + cardápio digital

Projeto demonstrativo feito com React, TypeScript, Vite e Tailwind CSS.

## Executar
```bash
npm install
npm run dev
```

## Publicar
```bash
npm run build
```
Publique a pasta `dist` em um serviço de hospedagem estática.

## Personalizar
- Edite os pratos, descrições, preços e categorias no array `dishes` em `src/App.tsx`.
- Troque as imagens pelos arquivos ou URLs do restaurante.
- O peixe acompanha o mouse no computador e o dedo em telas touch.
- O carrinho é demonstrativo; conecte o botão de pedido ao WhatsApp do estabelecimento para receber pedidos reais.
